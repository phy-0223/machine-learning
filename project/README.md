# 课程大作业执行手册

## 默认题目

完成一个**多类别图像分类项目**。优先选择类别定义清晰、许可允许教学使用、规模能在现有设备上完成的数据集。真实数据确定前，先运行 `python -m ml_course.cnn` 验证完整训练链路。

项目的科学问题必须先于模型确定：输入是什么、预测目标是什么、错误会造成什么后果、主指标为何符合实际代价。不要把“使用 CNN”当作问题定义。

## 里程碑与完成定义

### 第 3–4 周：题目冻结

- 一页问题说明：样本、标签、用户、使用情景与不使用情景；
- 数据来源、许可证、隐私和代表性风险；
- 主指标一个、辅助指标不超过三个；
- 明确测试集冻结策略。

### 第 6 周：数据与基线

- 检查重复、损坏图片、类别分布和分辨率；
- 固定 train/validation/test 划分及随机种子；
- 完成简单基线，例如多数类、线性分类器或浅层 CNN；
- 在 `experiment_log.csv` 登记结果。

### 第 10 周：主模型

- 完成 CNN 或迁移学习主模型；
- 保存完整配置、软件版本、随机种子与最优 checkpoint；
- 只用验证集选择 epoch、结构和超参数。

### 第 13 周：两项有依据的改进

只做能回答问题的对照实验，每次改变一个主要因素。推荐从以下选择两项：

1. 数据增强；
2. 权重衰减或 Dropout；
3. 学习率调度；
4. 类别加权；
5. 迁移学习与从头训练的公平比较。

改进失败也可以进入报告，但必须解释证据和可能原因。

### 第 14–15 周：误差分析与报告

- 训练/验证曲线；
- 测试集混淆矩阵和逐类 Precision、Recall、F1；
- 至少 20 个错误样本，按错误类型分组；
- 基线、主模型和两项改进的统一表格；
- 局限、偏差、隐私、误用风险与下一步；
- 让一位同学从空环境按 README 复现主要结果。

## 实验纪律

- 每次运行前填写假设与唯一改动，运行后填写结论；
- 随机种子固定为 42；若算力允许，最终方案再补 3 个种子并报告均值与标准差；
- 任何由测试集结果引发的模型修改都要明确披露，并重新建立真正独立的测试集；
- 图表必须带标题、坐标、单位、样本量或必要图例；
- 保存最后采用的环境依赖和数据划分清单，不提交隐私数据或大模型权重。
