# 期中闭卷自测参考答案

1. 监督学习利用带标签样本学习输入到目标的映射，如肿瘤分类；无监督学习在无标签数据中发现结构，如客户聚类。
2. 全数据标准化会让测试集均值和方差信息进入训练过程，使测试评价偏乐观。应先切分，再让 Pipeline 只在训练集或每个交叉验证训练折上拟合标准化器。
3. $\nabla L=2(w-3)$。$w_1=0-0.1(-6)=0.6$；$w_2=0.6-0.1(-4.8)=1.08$。
4. 过大可能震荡、发散或出现非有限值；过小则下降缓慢，在有限训练轮数内无法接近最优点。
5. KNN 的距离直接受数值尺度支配；决策树在单个特征上按阈值划分，单调缩放通常不改变样本排序和划分。
6. 明显过拟合。可限制深度/叶节点、增加最小叶样本数、剪枝、增加训练数据，或用交叉验证选择复杂度；任答两项。
7. Precision=$80/(80+20)=0.8$；Recall=$80/(80+40)=2/3$；Accuracy=$940/1000=0.94$。筛查通常优先关注 Recall，因为漏诊代价高，但最终阈值仍需结合误诊代价和资源约束。
8. 训练集拟合参数，验证集/交叉验证选择模型和超参数，测试集只提供最终无偏近似。反复依据测试结果调参会让测试集事实上成为验证集，使结果偏乐观，需另取新测试集才能重新评价。
