# 算法六问模板

每学一个算法复制本页并填写。答案应尽量用自己的语言，不超过两页。

## 算法：__________　日期：__________

1. **解决什么问题？** 任务类型、典型场景和不适用场景是什么？

2. **输入与输出是什么？** 写出张量/矩阵形状、数据类型和输出含义。

3. **目标函数是什么？** 写出公式，逐个解释符号；如果没有显式目标函数，说明其决策规则。

4. **参数如何学习？** 训练步骤、关键超参数、计算与存储成本是什么？

5. **如何评价？** 主指标与辅助指标是什么？为什么它们符合实际代价？

6. **什么时候会失败？** 至少列出数据、建模假设、优化和社会影响四类中的三类风险。

## 一分钟口述

不用术语堆砌，向没有学过该算法的同学解释它。录音后检查是否回答了“为什么用、怎么学、如何知道它有效”。
